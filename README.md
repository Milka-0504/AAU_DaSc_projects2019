# AAU Data Science Project

## 1. Project Overview

This project demonstrates basic Git and GitHub operations using a
simple Python script that creates a sample dataset.

## 2. Objectives

- Create a local Git repository.
- Track changes and create commits.
- Connect a local repository to GitHub.
- Practice pushing and pulling changes.
- Document a project using Markdown.

## 3. Project Files

| File | Description |
|---|---|
| `Calculate_BMI.py` | Calculates BMI |

## 4. Requirements

- Git
- Python 3

## 5. Installation and Usage

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

```bash
python Calculate_BMI.py
```

On Windows, you can also try `py Calculate_BMI.py`.


## 6. Sample Code Description

The project folder contains a python code that calculates MBI. It gets an inputs -Height and Weight from a user and calculates the BMI. Based on the output, it displays the catagory in with the user is in, "Normal","Under weight", and "Over weight"

- BMI = bmi = w/(h**2)
